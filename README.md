Quizzler 🧠

An interactive quiz application built with Flutter and Dart.

This project explores application logic, question-and-answer handling, user interaction, and state management in a mobile application.

📱 Overview

Quizzler is a quiz application that presents questions and allows users to select answers.

The application evaluates responses and provides an interactive way to explore basic quiz functionality.

✨ Features

* Interactive quiz questions
* Answer selection
* Feedback based on user responses
* Question progression
* Stateful user interface

The exact features depend on the implementation in this repository.

🛠️ Tech Stack

* Framework: Flutter
* Language: Dart
* Concepts: Conditional logic, data structures, state management, and event handling

📚 Key Learnings

* Organizing questions and answers in Dart
* Working with lists and structured data
* Implementing conditional logic
* Managing application state
* Responding to user input
* Building interactive application flows

🚀 Getting Started

Prerequisites

* Flutter SDK
* Dart SDK
* A configured emulator or physical device

Installation

1. Clone the repository:

git clone https://github.com/vsroshan/flutter-quizzler.git

2. Navigate into the project directory:

cd flutter-quizzler

3. Install dependencies:

flutter pub get

4. Run the application:

flutter run
